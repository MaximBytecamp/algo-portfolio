# Занятие 5 · Исследования алгоритмов с ИИ

В папке `issledovaniya-algoritmov/` лежат 12 бланков исследований. Преподаватель назначает один или несколько файлов.

```
lesson_05/
  issledovaniya-algoritmov/
    README.md
    01-minimum.md
    …
    12-first-repeat.md
  solutions.py
  test_lesson_05.py
```

## Что делать

1. Откройте назначенный `.md`.
2. После собственной идеи попросите ИИ предложить 8 вариантов решения.
3. Реализуйте варианты в `solutions.py`.
4. Добавьте тесты в `test_lesson_05.py`.
5. Сделайте замеры и заполните таблицу в своём `.md`.
6. Выберите вариант для двух сценариев.

## Запуск

```bash
pytest lesson_05
```
