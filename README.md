# algo-portfolio · ОП.04 «Основы алгоритмизации и программирования»

Ваш репозиторий на всю дисциплину: решения задач, тесты к ним и короткие
заметки о том, сколько решение стоит по времени и памяти. К концу курса это
и есть портфолио, которое можно показать на собеседовании.

## Как сделать его своим

Это шаблон. На странице репозитория нажмите **Use this template →
Create a new repository**, назовите `algo-portfolio` и выберите видимость.
У вас появится собственный репозиторий с чистой историей — он остаётся у вас
и после дисциплины.

Форк не подходит: он остаётся привязан к исходному репозиторию.

## Первый запуск

Нужен **Python 3.12** и **git**. Проверить, что они установлены:

| | macOS / Linux | Windows (PowerShell) |
|---|---|---|
| версия Python | `python3 --version` | `py --version` |
| версия git | `git --version` | `git --version` |

Если Python не найден — поставьте его с python.org, при установке на Windows
отметьте галочку **Add Python to PATH**.

**macOS / Linux**

```bash
git clone <адрес вашего репозитория> algo-portfolio
cd algo-portfolio

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

pytest
```

**Windows (PowerShell)**

```powershell
git clone <адрес вашего репозитория> algo-portfolio
cd algo-portfolio

py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt

pytest
```

Если PowerShell не даёт запустить `Activate.ps1`, один раз выполните
`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` и повторите.
В обычной командной строке (cmd) активация выглядит так: `.venv\Scripts\activate.bat`.

Должно получиться `2 passed` — Python подходящей версии и pytest работает.
Перед каждой работой окружение нужно активировать заново: строка приглашения
начнётся с `(.venv)`.

## Что где лежит

```
test_setup.py   проверка окружения, трогать не нужно
lesson_01/      занятие 1: домашнее задание и место для вашего решения
```

Задачу и заготовку решения преподаватель выдаёт на паре — вы кладёте их
в папку занятия. Внутри папки всегда одно и то же:

| Файл | Что в нём |
|---|---|
| `solution.py` | ваш код |
| `test_lesson_NN.py` | ваши тесты: обычный случай и границы |
| `homework_NN.md` | домашнее задание |

Папку для следующего занятия делаете копией предыдущей:

- macOS / Linux: `cp -r lesson_01 lesson_02`
- Windows: `Copy-Item -Recurse lesson_01 lesson_02` (или скопировать в проводнике)

## Как сдавать

```bash
git switch -c hw-01                       # ветка на задание
# ... пишете ...
pytest lesson_01                          # тесты вашей папки
git add lesson_01
git commit -m "hw-01: три алгоритма из дня"
git push -u origin hw-01
```

Команды git одинаковые во всех системах. Дальше на GitHub открываете
**Pull Request** в свою `main` и коротко пишете: что за задача, какой подход
выбрали, сколько он стоит по времени и памяти, какие тесты добавили.

Срок — до начала следующего занятия.

## Правила

- На тренировке ИИ можно **после собственной попытки**: попросить review,
  придумать дополнительные тесты, оформить готовые мысли в `.md`. Ответ
  проверяете запуском и отмечаете, что изменили.
- На диагностике, mock-интервью, контестах и экзамене ИИ, поиск и
  автодополнение закрыты.
- Тесты должны запускаться у другого человека после `git clone`.
