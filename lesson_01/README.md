# Занятие 1

**На паре разобрали:** алгоритмы вокруг нас, определение алгоритма, инвариант,
разницу между списком и множеством, формат алгоритмической секции.

**Что сюда положить.** Задачу и заготовку решения преподаватель выдаёт на
паре. Файлы кладёте в эту папку:

```
lesson_01/
  solution.py         ваш код
  test_lesson_01.py   ваши тесты: обычный случай и границы
  homework_01.md      домашнее задание (уже здесь)
```

**Запуск тестов**

```bash
pytest lesson_01
```

**Домашнее задание** — `homework_01.md`, к следующей паре. Кода в нём не нужно.
